---
description: Scaffold a new project or adopt an existing codebase into the create-project workflow
argument-hint: [project name or one-line description]
---
Invoke the **create-project** skill with arguments `mode=init $ARGUMENTS`.

This interviews you about what you're building, then auto-detects whether the current directory is a new scaffold or an existing codebase to adopt, and routes to the right setup flow (tech / data / research / other, or existing-codebase adoption).
